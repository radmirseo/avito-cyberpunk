# Настройка Авито — сайт-визитка

Адаптивная страница в киберпанк-стиле. Телефон: +79600666226.

## Запуск

Откройте `dist/index.html` или запустите из корня проекта:

```sh
python3 -m http.server 8080 --directory dist
```

Сайт доступен по http://localhost:8080. Сборка и установка зависимостей не нужны.

## Состав

- `dist/index.html` — текст и структура страницы.
- `dist/styles.css` — оформление и адаптация под мобильные устройства.
- `dist/script.js` — копирование номера (в защищённом контексте HTTPS или localhost).
- `.openai/hosting.json` — конфигурация Sites.

## GitHub Pages

В настройках репозитория Pages выберите GitHub Actions. Включённый workflow публикует папку `dist` при push в `main` или ручном запуске. Доступность Pages зависит от настроек аккаунта и репозитория.

Кнопки звонка используют `tel:+79600666226`. На компьютере для звонка требуется приложение, поддерживающее телефонные ссылки. Внешних шрифтов, аналитики и форм сбора данных нет.
